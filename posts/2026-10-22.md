Sometimes you want your terminal to send its internet traffic through a VPN or proxy, and sometimes you don’t. Typing long export commands every time gets tedious. This guide shows you how to add three short commands to your terminal:

- `proxy_on` turns the proxy on for the current terminal.
- `proxy_off `turns it off.
- `proxy_status` shows whether it’s on and where it’s pointing.

## Before You Start

You need three things:

A running proxy client. This guide uses Clash, which listens on a local “port” (a numbered doorway on your computer) of 7897. Open your Clash app and confirm it’s running. If you use a different client, or a different port, you’ll change the number in the steps below.

A terminal. Any terminal app works.

Basic comfort with a text editor. You’ll paste a block of text into a file called .bashrc, which is a settings file that runs every time you open a terminal.

> **What’s a proxy?** A proxy is a middleman. Your traffic goes to the proxy first, and the proxy forwards it to the internet. This can hide your location or route traffic through a VPN. When the proxy is off, your traffic goes straight out as usual.
 
### Step 1: Open Your `.bashrc` File

In your terminal, type:

```bash
nano ~/.bashrc
```

`nano` is a simple text editor that runs in the terminal. The `~` symbol means your home folder, so `~/.bashrc` is your personal settings file.

Scroll to the bottom of the file using the arrow keys.


### Step 2: Paste the Proxy Functions

Copy the block below and paste it at the bottom of the file:

```bash
# --- Proxy Toggles for Clash Mixed Port ---
proxy_on() {
    export http_proxy="http://127.0.0.1:7897"
    export https_proxy="http://127.0.0.1:7897"
    export HTTP_PROXY="http://127.0.0.1:7897"
    export HTTPS_PROXY="http://127.0.0.1:7897"
    export all_proxy="socks5h://127.0.0.1:7897"
    export ALL_PROXY="socks5h://127.0.0.1:7897"
    alias sudo='sudo -E '
    echo -e "\e[1;32m[✔] Terminal proxy routing enabled (127.0.0.1:7897), sudo -E enabled\e[0m"
}

proxy_off() {
    unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY all_proxy ALL_PROXY
    unalias sudo 2>/dev/null
    echo -e "\e[1;31m[✘] Terminal proxy routing disabled. sudo -E disabled\e[0m"
}

proxy_status() {
    echo "Current Proxy Configuration:"
    echo "----------------------------"
    echo "http_proxy  = $http_proxy"
    echo "https_proxy = $https_proxy"
    echo "all_proxy   = $all_proxy"
    if alias sudo &>/dev/null; then
        echo "sudo alias  = active (sudo -E)"
    else
        echo "sudo alias  = inactive"
    fi
}
```

Save and exit `nano`: press `Ctrl + O`, then `Enter` to save, then `Ctrl + X` to exit.

> **Tip:** Only paste this block once. If you paste it twice, the functions get defined twice. Nothing breaks, but the file gets messy.

### Step 3: Load the New Commands

Your terminal only reads `.bashrc` when it starts, so either open a new terminal window or run:

```bash
source ~/.bashrc
```

### Step 4: Try It Out

**Turn the proxy on:**
```bash
proxy_on
```

You should see a green message confirming the proxy is enabled.

**Check the status:**
```bash
proxy_status
```

This prints the proxy addresses currently in use and whether the `sudo` shortcut is active.

**Turn the proxy off:**
```bash
proxy_off
```
You should see a red message confirming it’s disabled.


### Step 5: Confirm It Really Works

Commands like `proxy_on` only change your terminal, so the best test is to see whether your internet address changes. Run this while the proxy is on:

```bash
curl https://ifconfig.me
```

Then run `proxy_off` and try again. If the address differs between the two runs, the proxy is working. (`curl` is a command-line tool for fetching web pages. It’s installed on most Linux systems. On Fedora, you can install it with `sudo dnf install curl` if needed.)

### How It Works, in Plain English

Each function does a simple job:
- `proxy_on` sets several _environment variables_. These are named notes that programs read when they start. Many command-line tools, such as `curl`, `wget`, and `git`, check these notes and send their traffic through the proxy if they find one. The variables come in both lowercase and uppercase because different programs look for different versions.
- The `socks5h` lines use a different proxy protocol called SOCKS5. The `h` at the end means DNS lookups (converting website names into addresses) also go through the proxy, which avoids leaking which sites you visit.
- `alias sudo='sudo -E '` creates a shortcut so that when you type `sudo`, it runs as `sudo -E`. The `-E` flag keeps your proxy settings when running commands as administrator. Without it, `sudo` usually wipes your environment, and proxy settings disappear.
- `proxy_off` removes all these variables and the `sudo` shortcut. The `2>/dev/null` part hides any error message if the alias was never set.
- `proxy_status` prints the current values so you can see what’s active.


### Troubleshooting

**command not found: proxy_on**  
You probably didn’t reload your settings. Open a new terminal or run `source ~/.bashrc`. Also check that you pasted the code into `~/.bashrc` and not a different file.

**The proxy is on, but websites don’t load**  
Your proxy client probably isn’t running, or it’s using a different port. Open your Clash settings, find the “Mixed Port,” and compare it with `7897`. If it differs, edit the numbers in `.bashrc`.

**`curl` shows the same address with the proxy on and off**  
Check that Clash is running and that “system proxy” or “allow LAN” is enabled in its settings, depending on your version. Then run `proxy_status` to confirm the variables are set.

**Some apps ignore the proxy**  
This is normal. These settings only affect programs started from the terminal where you ran `proxy_on`. Graphical apps like your web browser don’t read terminal settings, so you’ll need to set their proxy separately.

### Limitations to Know

- The change applies only to the terminal window where you ran `proxy_on`. Other windows stay unchanged.
- Closing the terminal clears the settings. This is a feature: each new terminal starts with no proxy unless you ask for one.
- Some programs need their own proxy configuration and ignore these variables.

### Make It Your Own

If your proxy uses a different port, change `7897` everywhere it appears in the block. It appears in eight places, so use your editor’s find-and-replace feature to update them all at once. In `nano`, press `Ctrl + \`, type the old number, press `Enter`, type the new number, and press `Enter` again.

Once you’re comfortable, you can also add a shortcut to the top of your file so you only have to change the port in one spot:

```bash
PROXY_PORT=7897
```

Then replace each `127.0.0.1:7897` with `127.0.0.1:$PROXY_PORT`, and the same for `socks5h`. Now a future port change takes a single edit.

---
That’s it. You now have a simple switch for your terminal’s internet routing, and you understand what each piece does. If something doesn’t behave the way this guide describes, check the troubleshooting section first, then try `proxy_status` to see what’s actually set.
